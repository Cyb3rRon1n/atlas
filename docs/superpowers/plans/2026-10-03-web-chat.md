# Web Chat + Approve — Implementation Plan (PR 4 of 5)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a **Chat** tab to atlas web. It talks to the same assistant as `atlas-chat` (the same `AtlasAgent`, tools and notes), shows any suggested action or plan with an **Approve** button per step, and runs an approved step through the existing action registry after re-checking it against live state. Every turn and every executed step is published as an event, so it shows in History. The map's side panel gets an "Ask atlas about this device" link.

**Architecture:**
- `atlas/web/chat.py` holds the conversation logic: in-memory sessions keyed by a random id, idle expiry, a turn cap, `chat_turn()` which wraps `AtlasAgent.converse`, and `execute_step()` which grounds and then executes.
- `atlas/web/api.py` adds `POST /api/chat` and `POST /api/actions/execute`. Both sit behind the existing same-origin gate.
- `atlas/web/chat_page.py` renders `/chat` with one inline script. There is no new dependency.

**Tech Stack:** stdlib `http.server` and `secrets`, the existing `atlas.intelligence` (`get_provider`, `AtlasAgent`, `ChatReply`), `atlas.actions` (`ACTIONS`, `is_action_grounded`, `execute_action`), pytest.

**Spec:** `docs/superpowers/specs/2026-09-29-network-inventory-design.md`, delivery step 4 ("The Chat tab and Approve"). See the Web UI section's "Chat" and "Approve" bullets.

## Global Constraints

- No new dependency. Executable actions are exactly the `ACTIONS` registry. An action is **re-grounded against freshly collected live state immediately before it runs** (`is_action_grounded`). If it isn't grounded, the endpoint returns **409** `{"error": "target no longer exists / state changed"}` and nothing runs.
- Approve runs **one step per request**. The page enables step N+1 only after step N succeeded. A failed or declined step stops the plan, which matches the CLI's "a failed step always stops the rest".
- Every executed step publishes the **same event type the CLI uses** (`PLAN_STEP_EVENT_TYPES[action.type]`) with source `"AtlasWeb"` and payload `{"target", "result"}`. Every chat turn publishes `atlas.chat.turn` with `{"session", "question", "answer", "action", "plan"}`. Everything in these payloads is a plain JSON value.
- Sessions:
  - They live in memory only.
  - Ids come from `secrets.token_urlsafe(16)`.
  - A session is discarded after **2 hours idle**.
  - It is capped at **20 turns**. After that, the reply says the session is full and the client starts a new one.
  - All access is guarded by a `threading.Lock`, because the server is a `ThreadingHTTPServer`.
- Provider failures (`AIProviderError`, an unreachable Ollama) return **502** `{"error": "<message>"}`. Other tabs are unaffected.
- The page writes text only with `textContent`. Never `innerHTML`. Approve sends the action object exactly as the reply gave it.
- Tests never call a real LLM or Docker. They monkeypatch `get_provider`/`AtlasAgent.converse`, `_live_environment`, and `execute_action`.
- Commits carry no AI-attribution trailer. Code follows the repo's heavy vertical spacing.
- Run tests with `.venv/bin/python -m pytest tests/ -q` from the repo root.

```python
"""
The web chat: the same AtlasAgent as `atlas chat`, behind /api/chat, with
in-memory per-browser sessions, plus Approve, which executes exactly one
suggested step after re-grounding it against live state. Pure of HTTP:
callers pass factories, so tests never touch an LLM or Docker.
"""

import secrets
import threading
import time
from dataclasses import asdict

from atlas.actions import ACTIONS, PLAN_STEP_EVENT_TYPES, execute_action, is_action_grounded
from atlas.core.application import application
from atlas.events import AtlasEvent
from atlas.intelligence.providers.base import AIProviderError, SuggestedAction


ACTION_FIELDS = ("type", "target", "cpus", "memory")


def _publish(event_type, payload):

    try:
        application.runtime.events.publish(AtlasEvent(event_type=event_type, source="AtlasWeb", payload=payload))

    except Exception as error:  # the action/answer already happened; a logging failure must not hide it
        print(f"atlas web: could not record {event_type}: {error}")


class ChatSessions:

    def __init__(self, idle_seconds=7200, max_turns=20):

        self.idle_seconds = idle_seconds
        self.max_turns = max_turns
        self.lock = threading.Lock()
        self.sessions = {}

    def prune(self, now=None):

        now = time.time() if now is None else now

        for key in [key for key, session in self.sessions.items() if now - session["last"] > self.idle_seconds]:
            del self.sessions[key]

    def get_or_create(self, session_id, now=None):

        now = time.time() if now is None else now
        self.prune(now)

        if session_id not in self.sessions:
            session_id = secrets.token_urlsafe(16)
            self.sessions[session_id] = {"messages": [], "turns": 0, "last": now}

        self.sessions[session_id]["last"] = now

        return session_id, self.sessions[session_id]


def _action_dict(action):

    definition = ACTIONS.get(action.type)
    data = {key: getattr(action, key) for key in ACTION_FIELDS}
    data["command"] = definition.command_template(action) if definition else None

    return data


def reply_to_dict(reply):

    return {
        "text": reply.text,
        "action": _action_dict(reply.action) if reply.action else None,
        "plan": {
            "summary": reply.plan.summary,
            "steps": [{"action": _action_dict(step.action), "rationale": step.rationale} for step in reply.plan.steps],
        } if reply.plan else None,
    }


def chat_turn(sessions, session_id, message, agent_factory, now=None):

    if not isinstance(message, str) or not message.strip():
        return 400, {"error": "message must be non-empty text"}

    with sessions.lock:
        session_id, session = sessions.get_or_create(session_id, now)

        if session["turns"] >= sessions.max_turns:
            del sessions.sessions[session_id]
            session_id, session = sessions.get_or_create(None, now)
            return 200, {"session": session_id, "text": "This conversation is full - starting a new one. Ask again.",
                         "action": None, "plan": None, "reset": True}

        messages = list(session["messages"]) + [{"role": "user", "content": message}]

    # The LLM call happens outside the lock: it can take 10-30 s and must not block other sessions.
    try:
        reply = agent_factory().converse(messages)

    except AIProviderError as error:
        return 502, {"error": str(error)}

    data = reply_to_dict(reply)

    with sessions.lock:
        session["messages"] = messages
        session["turns"] += 1

    _publish("atlas.chat.turn", {"session": session_id, "question": message, "answer": data["text"],
                                 "action": data["action"], "plan": data["plan"]})

    return 200, {"session": session_id, **data}


def execute_step(action_data, environment_factory, executor=execute_action):
    """One approved step: re-ground against live state, run it, record it - same event as the CLI."""

    if not isinstance(action_data, dict) or action_data.get("type") not in ACTIONS \
            or not isinstance(action_data.get("target"), str):
        return 400, {"error": "action must be a known action type with a target"}

    action = SuggestedAction(**{key: action_data.get(key) for key in ACTION_FIELDS})

    if not is_action_grounded(action, environment_factory()):
        return 409, {"error": "target no longer exists / state changed"}

    result = executor(action)
    _publish(PLAN_STEP_EVENT_TYPES[action.type], {"target": action.target, "result": result})

    return 200, {"ok": bool(result.get("success")), "result": result}
```

`asdict` is imported, but the code above doesn't use it. Remove the import if nothing ends up needing it. `PLAN_STEP_EVENT_TYPES` must cover every `ACTIONS` key that the executor supports. If an `ACTIONS` key is missing from it, `execute_step` would raise a KeyError. Handle that by falling back to `"atlas.action.executed"`, and note it.
